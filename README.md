 Alina Martin – Personal Portfolio Website

A modern, responsive portfolio website showcasing my skills, projects, education, and contact information. Built with HTML5 and Bootstrap 5 featuring separate pages for easy navigation.

 Features

- Multi-page structure — Separate HTML files for each section
- Working contact form — Integrated with Formspree for direct email submissions
- Fully responsive— Works on desktop, tablet, and mobile using Bootstrap's grid system
- Bootstrap 5 UI — Cards, progress bars, badges, navbar with mobile collapse, alerts, and list groups
- Bootstrap Icons— Icon set used throughout all pages
- CV download — Easy access to download the CV from multiple locations
- No-redirect form — Custom success message without leaving the page

 
 Pages
| File | Description |
|------|-------------|
| `index (1).html` | Home — hero section, quick-nav cards |
| `about (1).html` | About — personal story, values, CV download |
| `skills (1).html` | Skills — progress bars for each skill |
| `projects (1).html` | Projects — Bootstrap cards with images and badges |
| `education (1).html` | Education — timeline layout using Bootstrap flex utilities |
| `contact (1).html` | Contact — form + contact detail list group |


 Technologies Used

- HTML5
- Bootstrap 5.3.3 — layout, components, and utility classes
- Bootstrap Icons 1.11.3 — icon set
- JavaScript— async contact form submission
- Formspree— contact form backend

> No custom CSS file is used. All styling is done exclusively with Bootstrap 5 utility classes and components.
